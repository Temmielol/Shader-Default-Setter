# Shader Default Setter

A small Unity editor tool that writes a material's current property values back
into its shader source as the new default values.

## Usage

Two ways to run it:

- Right click the material header in the Inspector (or use the small menu icon)
  and pick **Apply Values To Shader Defaults**.
- Open **Temmie > Shader Default Setter**, drag in a material, and click the button.
